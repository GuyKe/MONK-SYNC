# MONK-SYNC

Unity VR game: arm-locomotion movement in a procedural Backrooms. See [docs/PLAN.md](docs/PLAN.md).

## Open the project
1. Unity Hub > Add project from disk > this folder. Use Unity 6 (6000.0.x); it will generate `ProjectSettings` and `.meta` files. Commit the `.meta` files.
2. Project Settings > Graphics: use a URP asset (Quest: Mobile URP). Player > Android: Vulkan, ARM64, IL2CPP.
3. XR Plug-in Management > OpenXR (enable Oculus Touch Controller Profile; Meta Quest feature group on Android).
4. Physics > Fixed Timestep: `0.01111` (90 Hz).

## M1: locomotion gym
1. New empty scene, then menu **Monk > Build M1 Locomotion Gym**. It creates the whitebox gym, the rig (`ArmLocomotion`), and `Assets/_Monk/LocomotionProfile.asset`.
2. Press Play with a headset (Link / Air Link) or build to Quest.
3. Tune values in the `LocomotionProfile` asset. Select `PlayerRig` to see gizmos: cyan = body, green = stuck hand, magenta = velocity.

Walkable geometry must use box/sphere/capsule/convex colliders (body penetration resolve needs them).

Tests: Window > General > Test Runner > EditMode.

## Locomotion rules
- **Hand-contact propulsion:** pushing a hand into geometry moves the body the opposite way; real hand velocity becomes momentum when the last hand lets go.
- **No legs / no stick walking:** there is no thumbstick locomotion. The avatar is a torso and arms (`UpperBodyAvatar`).
- **Surface slip:** `SurfaceProperties.slipPercentage` (0 = rough bark, full traction; 1 = ice, hands slide). Presets: Rough, Normal, Smooth, Slick, Ice. The gym's north wall has one strip per preset.
- **Arm-span scaling:** hold both grips with arms stretched out for 1.5 s (`ArmSpanCalibrator`). Hand reach scales by `referenceArmSpan / measuredSpan`, saved in PlayerPrefs.

## M2: the Backrooms map
Menu **Monk > Build Backrooms Map** (empty scene, URP assigned) generates the level, the player rig and all gameplay. Save the scene afterwards. **Monk > Build Backrooms Map (new random layout)** builds a different layout (a new seed). Run either again to rebuild.

- **Big and seeded:** a 42 x 42 cell (168 m) maze generated by `Scripts/World/MapLayout.cs`: thin partition walls, dead ends, loops, wide open lobbies, flooded areas and doors in straight corridors. `MapLayout.Generate(seed)` is deterministic; EditMode tests check every walkable cell is reachable from every start room.
- **Random spawn:** the same start room (concrete research room, airlock, window onto an atrium) is stamped 7 times around the map. `RandomSpawn` puts you in a random one every time you press Play (set `forcedIndex` on the rig to test one). Entering any start room sets it as your respawn point.
- **Backrooms feel:** three looks that change across the map (classic yellow wallpaper and beige carpet; pale office with grey carpet tiles and wood wainscot; mold with dark green-brown carpet, mold patches and more dead lights), pillar halls, tall halls with catwalks, wet pool-tile flooded areas, long corridors of identical doors and flickering panels, dead ends with abandoned desks, crates and tally marks.
- **Textures** are generated in code, 22 of them (3 wallpapers, 3 carpets, 2 ceiling tiles, pool tile, linoleum, wood, drywall, concrete, metal, crates, fabric, hazard stripes and decals for peeling paper, water stains, mold, cracks, tally marks, spray arrows). They land in `Assets/_Monk/Art/Generated` (delete with Monk > Delete Generated Map Textures to regenerate). Every sound is synthesised at runtime, so there are no art or audio files to import.
- **Landmarks:** The Pitfalls (deep square drops, narrow walkways, hanging pipes; x2), server / relay stations (x2), flooded halls with reflective water, tall halls with a climbable catwalk (x2).
- **Verticality:** crate stacks, broken drywall holes cut through partitions, ventilation ducts you can climb into, shelving, cubicles, knocked-over dividers, ceiling pipes.
- **Doors:** every door rises into a housing above the ceiling. Fire doors are manual, blast doors cycle automatically, the airlock leads out of each start room. Slap a button or lever. Closing = warning sparks and beeps, then a heavy drop; being under it eliminates you. Nothing is placed in front of or behind a door.
- **Glass:** the observation window is two clear panes. Slap one hard (about 3 m/s) and it shatters into physical shards.
- **Lighting and audio:** about 1,700 emissive ceiling panels (steady, flickering, dead) but only 4 real lights, which follow the nearest working panels. The buzz rises in pitch near a panel; vents rumble and clank; carpet squelches; a hallway reverb zone.
- **Hazards:** door crush and pit drops. Elimination respawns you at the last start room you reached.

### Performance
The map is built in 24 m blocks and `ChunkVisibility` keeps only the blocks within about 56 m of you active, hidden in fog. Floors, ceilings and walls are merged into runs and batching-static. Still, 168 m of dense geometry is a lot for a standalone headset: if Quest struggles, lower `radius` on `ChunkVisibility`, raise the fog density, or reduce `DefaultSize` in `MapLayout`.
